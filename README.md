# Baby, Choose Carefully 💗

A tiny, cute, mobile-friendly boyfriend quiz.

## Upload to GitHub

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then save.
6. Wait for GitHub Pages to publish your site.

## Quiz behaviour

- One question appears at a time.
- YES and NO both reveal their cheeky response on the same page.
- He can switch between YES and NO; the response updates immediately.
- He can move to the next question only after choosing an answer.
- The final page ends with a sweet message.

No build tools, packages, or API keys are required.
